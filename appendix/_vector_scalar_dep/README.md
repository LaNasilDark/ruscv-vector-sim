# Vector-Scalar Dependency Test

## 概述

这个测试用例专门用于测试RISC-V向量模拟器中向量指令与标量指令之间的依赖关系处理。模拟器需要正确检测和处理这些依赖关系，确保指令按正确的顺序执行。

## 测试场景

### Test 1: 向量指令依赖标量计算结果
- **场景**: 标量寄存器计算 → 向量指令使用该标量结果
- **依赖类型**: 真数据依赖 (RAW - Read After Write)
- **测试内容**: 
  - 标量计算缩放因子
  - 向量指令使用该标量进行向量-标量乘法
- **预期行为**: 向量指令必须等待标量计算完成

### Test 2: 向量内存访问依赖标量地址计算
- **场景**: 标量寄存器计算地址偏移 → 向量加载指令使用该地址
- **依赖类型**: 地址依赖
- **测试内容**:
  - 标量计算内存偏移地址
  - 向量加载指令从计算出的地址读取数据
- **预期行为**: 向量内存指令必须等待地址计算完成

### Test 3: 混合标量-向量依赖链
- **场景**: 标量计算 → 向量操作 → 标量归约 → 向量操作
- **依赖类型**: 复杂的依赖链
- **测试内容**:
  - 多层次的标量-向量依赖关系
  - 向量归约操作产生标量结果
  - 后续向量操作依赖归约结果
- **预期行为**: 每个阶段都必须按顺序执行

### Test 4: 条件分支中的标量-向量依赖
- **场景**: 标量条件判断 → 影响向量操作的执行路径
- **依赖类型**: 控制依赖
- **测试内容**:
  - 标量计算决定分支条件
  - 不同分支执行不同的向量操作
- **预期行为**: 分支判断必须在向量操作之前完成

## 依赖检查要点

### 1. RAW依赖检查
- 向量指令读取的标量寄存器是否有未完成的写操作
- 模拟器应调用 `can_issue_vector_instruction()` 进行检查

### 2. 地址依赖检查
- 向量内存指令使用的地址寄存器是否有未完成的写操作
- 模拟器应调用 `can_issue_memory_instruction()` 进行检查

### 3. 混合寄存器类型处理
- 标量寄存器: 严格的写后读检查
- 向量寄存器: 允许并发访问，但有端口限制

### 4. 数据转发机制
- 测试部分结果的提前转发
- 验证向量寄存器任务队列的正确性

## 模拟器验证要点

运行此测试时，模拟器应该：

1. **正确识别依赖**: 在`try_issue()`中正确识别标量-向量依赖
2. **阻止错误发射**: 当存在未解决的依赖时，阻止指令发射
3. **端口管理**: 正确管理向量寄存器的读写端口
4. **数据转发**: 在安全的情况下允许数据转发
